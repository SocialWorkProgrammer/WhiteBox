
# Docker와 Ubuntu, GPU를 이용한 AI 모델 학습

이 가이드는 Docker와 Ubuntu에서 GPU를 이용하여 AI 모델 학습을 설정하고 실행하는 자세한 단계들을 제공합니다.

## 1. 환경 설정

### 1.1 Docker 설치

1. **패키지 업데이트:**

   ```bash
   sudo apt-get update
   ```

2. **필수 패키지 설치:**

   ```bash
   sudo apt-get install apt-transport-https ca-certificates curl software-properties-common
   ```

3. **Docker의 공식 GPG 키 추가:**

   ```bash
   curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -
   ```

4. **Docker 저장소 설정:**

   ```bash
   sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
   ```

5. **Docker 설치:**

   ```bash
   sudo apt-get update
   sudo apt-get install docker-ce
   ```

6. **Docker 설치 확인:**

   ```bash
   docker --version
   ```

### 1.2 NVIDIA 드라이버 설치

1. **사용 가능한 NVIDIA 드라이버 버전 확인:**

   ```bash
   ubuntu-drivers devices
   ```

2. **추천 드라이버 설치:**

   ```bash
   sudo apt-get install nvidia-driver-<버전>
   ```

3. **시스템 재부팅:**

   ```bash
   sudo reboot
   ```

4. **GPU 설치 확인:**

   ```bash
   nvidia-smi
   ```

### 1.3 NVIDIA Docker(NVIDIA Container Toolkit) 설치

1. **NVIDIA 패키지 저장소 추가:**

   ```bash
   curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
   distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
   sudo curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list
   ```

2. **업데이트 및 NVIDIA Container Toolkit 설치:**

   ```bash
   sudo apt-get update
   sudo apt-get install -y nvidia-container-toolkit
   ```

3. **Docker 재시작:**

   ```bash
   sudo systemctl restart docker
   ```

### 1.4 Docker Compose 설치

1. **Docker Compose 다운로드:**

   ```bash
   sudo curl -L "https://github.com/docker/compose/releases/download/$(curl -s https://api.github.com/repos/docker/compose/releases/latest | grep -oP '"tag_name": "\K(.*)(?=")')/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
   ```

2. **바이너리에 실행 권한 부여:**

   ```bash
   sudo chmod +x /usr/local/bin/docker-compose
   ```

3. **Docker Compose 설치 확인:**

   ```bash
   docker-compose --version
   ```

## 2. Docker 이미지 준비

### 2.1 Dockerfile 작성

프로젝트 디렉토리에 `Dockerfile`을 작성합니다. 아래는 PyTorch와 CUDA를 사용하는 예제 Dockerfile입니다:

```Dockerfile
# CUDA가 포함된 베이스 이미지 사용
FROM nvidia/cuda:11.7.0-cudnn8-devel-ubuntu22.04

# Python 및 필요한 시스템 패키지 설치
RUN apt-get update && apt-get install -y \
    python3-pip python3-dev git

# 작업 디렉토리 설정
WORKDIR /workspace

# requirements.txt 복사 및 종속성 설치
COPY requirements.txt .
RUN pip3 install --no-cache-dir -r requirements.txt

# 학습 코드 복사
COPY . .

# 학습 스크립트를 실행하는 명령어 설정
CMD ["python3", "train.py"]
```

### 2.2 AI 모델 종속성 설치

필요한 Python 패키지를 포함하는 `requirements.txt` 파일을 작성합니다:

```text
torch
torchvision
numpy
pandas
scikit-learn
matplotlib
```

Dockerfile에서 Docker 이미지를 빌드합니다:

```bash
docker build -t my-ai-model .
```

## 3. Docker 컨테이너 실행

### 3.1 Docker 컨테이너 시작

GPU 지원으로 Docker 컨테이너를 실행합니다:

```bash
docker run --gpus all -it --rm --name ai-training -v $(pwd):/workspace my-ai-model
```

- `--gpus all`: 사용 가능한 모든 GPU를 컨테이너에 할당합니다.
- `-it`: 인터랙티브 터미널 모드로 실행합니다.
- `--rm`: 종료 시 컨테이너를 자동으로 삭제합니다.
- `--name ai-training`: 컨테이너 이름을 `ai-training`으로 설정합니다.
- `-v $(pwd):/workspace`: 현재 디렉토리를 컨테이너의 `/workspace`에 마운트합니다.

### 3.2 GPU 할당 확인

컨테이너 내부에서 다음 명령을 실행합니다:

```bash
nvidia-smi
```

### 3.3 모델 학습 실행

모델 학습을 시작하려면 다음 명령을 실행합니다:

```bash
python3 train.py
```

이 단계들을 따라 Docker와 Ubuntu, GPU를 이용한 AI 모델 학습 환경을 설정하고 실행할 수 있습니다.
