# 이론 학습

## 1. 인공지능

1. 인공지능(Artificial Intelligence): 컴퓨터가 인간의 지능적 행동을 모방하도록 만드는 기술.

2. 인공지능은 하위 개념으로 머신러닝과 딥러닝을 포함함.

## 2. 머신러닝

1. **머신러닝(Machine Learning)**: 인공지능의 하위 분야로, 데이터를 분석하고 그 데이터로부터 패턴을 학습하여 의사결정을 내리거나 예측을 수행하는 기술.

    - **지도 학습(Supervised Learning)**: 데이터에 입력과 그에 대응하는 정답(레이블)이 포함된 경우, 이 데이터를 이용해 모델을 학습하는 방식.

    - **비지도 학습(Unsupervised Learning)**: 데이터에 정답이 없는 경우, 데이터의 구조나 패턴을 발견하기 위해 사용되는 학습 방식.

    - **강화 학습(Reinforcement Learning)**: 에이전트가 환경과 상호작용하며, 행동에 따른 보상을 통해 최적의 행동을 학습하는 방식.

    - **머신러닝의 주요 요소**: 데이터 전처리, 특징 추출, 모델 선택, 모델 평가.

## 3. 딥러닝

1. **딥러닝(Deep Learning)**: 머신러닝의 하위 분야로, 다층 신경망(Deep Neural Networks)을 사용하여 데이터로부터 고차원적인 패턴을 학습하는 기술.

    - **인공 신경망(Artificial Neural Networks, ANN)**: 인간의 뇌를 모방한 신경망 구조로 입력 데이터로부터 출력 값을 예측하는 모델.

    - **심층 신경망(Deep Neural Networks, DNN)**: 여러 개의 은닉층을 가진 신경망 구조로, 복잡한 데이터의 패턴을 학습할 수 있음.

    - **합성곱 신경망(Convolutional Neural Networks, CNN)**: 이미지나 시계열 데이터 처리에 주로 사용되는 딥러닝 모델.

    - **순환 신경망(Recurrent Neural Networks, RNN)**: 시퀀스 데이터를 처리하는 데 특화된 신경망으로, 이전 단계의 출력이 다음 단계의 입력으로 사용됨.

    - **Transformer**:
        - **Transformer**는 자연어 처리(NLP)에서 주로 사용되는 모델로, 시퀀스 데이터를 병렬로 처리할 수 있는 구조를 가지며, RNN의 순차 처리 한계를 극복한 모델.
        - 주요 구성 요소로는 **인코더(Encoder)**와 **디코더(Decoder)**가 있으며, 이들은 각각 다중 층으로 구성됨.
        - 인코더는 입력 문장을 고차원 벡터로 변환하고, 디코더는 이 벡터를 사용해 출력 문장을 생성함.

    - **Attention 메커니즘**:
        - Attention 메커니즘은 신경망이 입력 시퀀스의 각 부분에 할당하는 가중치를 학습하여, 특정 입력 부분에 더 집중할 수 있도록 함.
        - **Self-Attention**(또는 **Scaled Dot-Product Attention**): 입력 시퀀스의 각 위치가 시퀀스 내 다른 모든 위치와 상호작용하여 문맥을 이해하도록 함.
        - Attention은 인코더와 디코더 사이, 혹은 인코더 내에서 Self-Attention으로 적용되며, 긴 시퀀스에서 중요한 부분에 집중하도록 돕는다.
        - Attention 메커니즘의 수학적 정의는, Query, Key, Value라는 세 가지 입력 벡터를 사용하여, Query와 Key 간의 유사도에 따라 Value 벡터의 가중합을 계산하는 것.

    - **Transformer의 주요 요소**:
        - **멀티헤드 셀프 어텐션(Multi-Head Self-Attention)**: Attention 메커니즘을 여러 개 병렬로 적용해, 다른 표현 공간에서 다양한 측면의 정보를 학습함.
        - **포지셔널 인코딩(Positional Encoding)**: 시퀀스의 위치 정보를 인코딩에 추가하여 순서를 고려할 수 있도록 함.
        - **Layer Normalization**: 각 층에서의 학습을 안정화하기 위해 입력을 정규화하는 기법.
        - **피드 포워드 신경망(Feed-Forward Neural Networks)**: 각 Attention 모듈 뒤에 위치하며, 각 시퀀스 위치에서 독립적으로 처리됨.

    - **응용 분야**:
        - **자연어 처리(Natural Language Processing, NLP)**: 텍스트 생성, 번역, 감정 분석, 챗봇, 언어 모델링.
        - **컴퓨터 비전(Computer Vision)**: 이미지 생성, 이미지 캡셔닝, 객체 탐지.
        - **멀티모달 학습(Multimodal Learning)**: 텍스트, 이미지, 오디오 등 다양한 형태의 데이터를 함께 학습하는 응용.

# PyTorch 사용해보기
PyTorch : 파이썬 기반의 딥러닝 라이브러리로, 동적 계산 그래프를 이용하여 모델의 구조를 유연하게 변경할 수 있는 장점이 있다.

1. 설치 및 기본 사용법

    설치하기

    ```bash
        pip install torch
    ```
    
    기본적인 사용법 

    16개의 32 * 32 픽셀 크기를 가진 4차원 텐서를 생성하고, 1차원 벡터로 변환한다.

    ```python
    import torch
    import torch.nn as nn

    input_data = torch.zeros((16, 50))
    fc = nn.Linear(50, 10)
    output = fc(input_data)
    print(input_data)
    print(output)
    ```

    10차원의 입력을 50차원의 은닉층을 거쳐 1차원의 출력으로 생성하는 간단한 신경망

    ```python
    import torch.nn as nn
    import torch.nn.functional as F

    class SimpleNN(nn.Module):
        def __init__(self):
            super(SimpleNN, self).__init__()
            self.fc1 = nn.Linear(10, 50)
            self.fc2 = nn.Linear(50, 1)

        def forward(self, x):
            x = F.relu(self.fc1(x))
            x = self.fc2(x)
            return x

    # 모델 인스턴스 생성
    model = SimpleNN()
    ```

    가상의 데이터셋을 생성하고 데이터를 배치 단위로 나누어 처리하는 과정

    ```python
    from torch.utils.data import DataLoader, TensorDataset

    # 샘플 데이터 생성
    x_data = torch.randn(100, 10)
    y_data = torch.randn(100, 1)

    # TensorDataset 및 DataLoader
    dataset = TensorDataset(x_data, y_data)
    dataloader = DataLoader(dataset, batch_size=5, shuffle=True)

    # DataLoader 사용
    for batch_idx, (x_batch, y_batch) in enumerate(dataloader):
        print(f'Batch {batch_idx + 1}:')
        print(x_batch)
        print(y_batch)
    ```

    평균제곱오차(MSE)를 손실함수로 사용하고, 확률적 경사하강법(SGD)를 최적화 방법으로 이용하여 모델을 학습시키는 과정
    ```python
    import torch.optim as optim

    # 손실 함수 및 옵티마이저 설정
    criterion = nn.MSELoss()
    optimizer = optim.SGD(model.parameters(), lr=0.01)

    # 학습 루프
    for epoch in range(10):
        for x_batch, y_batch in dataloader:
            # 순전파
            outputs = model(x_batch)
            loss = criterion(outputs, y_batch)

            # 역전파 및 최적화
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

        print(f'Epoch {epoch+1}, Loss: {loss.item()}')
    ```

    모델의 성능을 평가하고 학습된 모델을 저장하고 불러오기
    ```python
    # 평가 모드로 전환
    model.eval()

    # 평가
    with torch.no_grad():
        total_loss = 0
        for x_batch, y_batch in dataloader:
            outputs = model(x_batch)
            loss = criterion(outputs, y_batch)
            total_loss += loss.item()

    print(f'Total Loss: {total_loss}') 

    # 모델 저장
    torch.save(model.state_dict(), 'simple_nn.pth')
    ```

    저장된 모델을 불러와 새로운 데이터에 대한 예측
    ```python
    # 모델 로드
    model = SimpleNN()
    model.load_state_dict(torch.load('simple_nn.pth'))
    model.eval()

    # 예측 수행
    with torch.no_grad():
        new_data = torch.randn(1, 10)
        prediction = model(new_data)
        print(f'Prediction: {prediction}')
    ```

# 과제상세 1. NumPy array와 PyTorch Tensor 다루기

두 데이터셋은 작동, 연산 방식이 유사하다.
Tensor를 이용한 데이터셋으로 여러 연산을 해보자.

```python
import torch

# 1. 차원 축소 (Squeeze)
tensor = torch.randn(1, 3, 1, 4) 
print("Original Tensor:", tensor.shape)

tensor_squeezed = tensor.squeeze()
print("Squeezed Tensor:", tensor_squeezed.shape)

# 2. 차원 확장 (Unsqueeze)
tensor_expanded = tensor_squeezed.unsqueeze(0) 
print("Expanded Tensor:", tensor_expanded.shape)

# 3. 축 변경 (Permute)
tensor_permuted = tensor.permute(1, 0, 2, 3) 
print("Permuted Tensor:", tensor_permuted.shape)

# 4. 행렬 붙이기 (Concatenate)
tensor_a = torch.randn(2, 3)  
tensor_b = torch.randn(2, 3) 
tensor_concat = torch.cat((tensor_a, tensor_b), dim=0)  
print("Concatenated Tensor:", tensor_concat.shape)

# 5. 행렬 간 연산
tensor_c = torch.randn(2, 3)
tensor_d = torch.randn(2, 3)

# 덧셈
tensor_add = tensor_c + tensor_d
print("Added Tensor:\n", tensor_add)

# 곱셈 (요소별 곱)
tensor_mul = tensor_c * tensor_d
print("Multiplied Tensor:\n", tensor_mul)

# 행렬 곱셈
tensor_matmul = torch.matmul(tensor_c, tensor_d.T) 
print("Matrix Multiplication:\n", tensor_matmul)
```
