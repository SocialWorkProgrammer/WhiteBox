# AiHub
AI-Hub는 한국지능정보사회진흥원이 운영하는 AI 통합 플랫폼이다.

2017년부터 진행한 인공지능 학습용 데이터 구축·확산 사업의 일환으로, AI 기술·서비스 개발에 필수적인 인공지능 학습용 데이터, 소프트웨어, 컴퓨팅자원 등을 원스톱으로 제공하는 것을 목적으로 한다.

=> 교통, 헬스 등 대략 840건의 데이터셋을 가지고 있기 때문에 이곳에서 데이터를 받고, 모델을 설정하여 학습시키면 수월할 것 같다.

# JavaScript에서의 비동기 방식

콜백 함수: 함수의 인자로 다른 함수를 전달하여, 작업이 끝난 후 호출되는 방식
=> 이해를 잘 하면 사람이 직접 순서를 지정할 수 있으나, 그러지 않은 경우 코드가 꼬일 수 있으므로 유의해야함

Promise: 비동기 작업의 결과를 나타내는 객체로, 성공 또는 실패 상태를 처리할 수 있음

async : 함수 앞에 async를 붙임 
await : 비동기 작업에 사용
=> Promise와 async를 같이 사용 가능한가?

setTimeout/setInterval: 지정된 시간 후에 코드를 실행하거나 일정 시간 간격으로 반복 실행하는 함수

fetch: 네트워크 요청을 처리하는 API로, Promise를 반환한다.
