# AiHub
AI-Hub는 한국지능정보사회진흥원이 운영하는 AI 통합 플랫폼이다.

2017년부터 진행한 인공지능 학습용 데이터 구축·확산 사업의 일환으로, AI 기술·서비스 개발에 필수적인 인공지능 학습용 데이터, 소프트웨어, 컴퓨팅자원 등을 원스톱으로 제공하는 것을 목적으로 한다.

=> 교통, 헬스 등 대략 840건의 데이터셋을 가지고 있기 때문에 이곳에서 데이터를 받고, 모델을 설정하여 학습시키면 수월할 것 같다.
https://aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&aihubDataSe=data&dataSetSn=597
