FastAPI의 특징과 프로젝트 생성 예제

FastAPI는 현대적이고, 빠르며(고성능), 파이썬 표준 타입 힌트에 기초한 Python의 API를 빌드하기 위한 웹 프레임워크입니다.

주요 특징:

고성능: Starlette과 Pydantic을 기반으로 하여 Node.js와 Go에 견줄 만큼 높은 성능을 자랑합니다. FastAPI는 가장 빠른 파이썬 프레임워크 중 하나입니다.

빠른 개발 속도: 코드 작성 속도가 약 200%에서 300%까지 빨라지며, 기능 개발이 더욱 신속해집니다.

적은 버그: 개발자의 실수를 약 40%까지 줄일 수 있어 코드의 품질이 높아지고 디버깅 시간이 줄어듭니다.

직관적 사용: 훌륭한 편집기 지원으로 모든 곳에서 자동 완성이 가능해 개발이 직관적이며, 디버깅에 걸리는 시간이 줄어듭니다.

사용과 학습이 쉬움: FastAPI는 쉽게 사용하고 배우도록 설계되어 있으며, 문서를 읽는 데 소요되는 시간이 적습니다.

짧은 코드: 코드 중복이 최소화되며, 각 매개변수 선언이 여러 기능을 수행해 코드가 간결해집니다.

견고한 프로덕션 준비: 자동 대화형 문서와 함께 프로덕션 환경에 바로 사용할 수 있는 견고한 코드를 제공합니다.

표준 기반: FastAPI는 OpenAPI(구 Swagger)와 JSON Schema와 같은 개방형 표준을 완전히 지원하여, API가 표준에 맞춰 개발될 수 있습니다.

```
from fastapi import FastAPI

# FastAPI 인스턴스 생성
app = FastAPI()

# 기본 루트 경로에 대한 GET 요청 처리
@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}

# /items/{item_id} 경로에 대한 GET 요청 처리
@app.get("/items/{item_id}")
def read_item(item_id: int, q: str = None):
    return {"item_id": item_id, "query": q}

# 새로운 아이템 생성하는 POST 요청 처리
@app.post("/items/")
def create_item(item: dict):
    return {"item_name": item["name"], "item_price": item["price"]}

# 실행: uvicorn main:app --reload
```
