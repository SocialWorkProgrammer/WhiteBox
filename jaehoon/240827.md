fastapi의 비동기 처리, request body, docs및 path

1. 비동기 endpoint
   async 와 await을 이용해 간편하게 구현 가능

```
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

2. request body
   Pydantic을 모델을 사용해 유효성 체크

```
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    description: str = None
    price: float
    tax: float = None

@app.post("/items/")
async def create_item(item: Item):
    return item
```

3. docs 자동화(swagger)
   /docs 링크를 통해 swagger 확인 가능

4. path, query 파라미터

```
@app.get("/items/{item_id}")
async def read_item(item_id: int, q: str = None):
    return {"item_id": item_id, "query": q}
```

=None을 통해 입력이 필수적인지 선택할 수 있음
