# 서버
### 서버관리에서 리눅스를 쓰는 이유?

- open source and free
- stability : 업데이트 이슈 해결됨
- secure and flexibility : 사용자 권한을 자유롭게 서정 가능

## Linux

- CLI 명령어
    - touch
    - cat : 파일 내용 보기
        - -e 옵션 : 줄 끝에 $ 보여주기
        - -n 옵션 : 줄 번호 보여주기
    - rm : 파일 삭제
    - mkdir : 디렉토리 만들기
    - rmdir : 디렉토리 삭제
    - cp : 파일 복사
    - mv : 파일 이동
    - ls : 현재 디렉토리 내 파일 리스트
        - -a 옵션 : 모두 보기(숨김 파일)
        - -l 옵션 : 길게 설명
        - -al 옵션 : 길게 모두 보기
    - sudo : 루트 권한으로 실행
    - apt / apt-get : Debian rlqks flsnrtm vozlwl rhksflwk ehrn
    - clear : 터미널 화면 비우기
